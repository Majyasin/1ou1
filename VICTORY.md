## 🚀 How to Use

### For Users:
1. Visit homepage
2. Type what you want to build
3. Click "Generate" or use a template
4. AI generates your project
5. Edit with Monaco editor
6. Test APIs with built-in tester
7. Deploy with one click
8. Share with friends!

### For Developers:
1. Clone repository
2. Copy `.env.example` to `.env.local`
3. Add required API keys
4. Run `npm install`
5. Run `npm run dev`
6. Visit `http://localhost:3000`
7. Start building!
